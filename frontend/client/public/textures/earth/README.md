# Earth textures

Not committed. Run `npm run fetch:textures` from the project root to download:

| File | Source |
|---|---|
| `earth_day.jpg` | three.js `examples/textures/planets/earth_atmos_2048.jpg` (NASA Blue Marble derived) |
| `earth_lights.png` | three.js `examples/textures/planets/earth_lights_2048.png` (NASA Earth at Night derived) |

Credit: NASA Visible Earth. Higher-resolution originals: https://visibleearth.nasa.gov/

If these files are missing, the globe still renders as a plain sphere and shows a notice.
